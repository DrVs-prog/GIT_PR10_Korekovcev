# Добро пожаловать в мой проект! 🎉

## О проекте

Этот репозиторий создан для демонстрации настроек конфигурации и настройки GIT и демонстрации использования Markdown-разметки.

### Что внутри?

- **Заголовки разных уровней**  
- _Курсивный_ и **жирный** текст  
- ~~Зачёркнутый~~ текст

- Таблицы  
- Вставки кода  
- Ссылки
